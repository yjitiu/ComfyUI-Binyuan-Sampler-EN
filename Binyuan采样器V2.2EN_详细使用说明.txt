Binyuan Sampler V2.2 EN｜中英双语版使用说明

更新日期：2026-09-28
节点标识：BinyuanUltimateSamplerEN

一、安装、更新与分发

把整个 binyuan_sampler_plugin_english 文件夹放进 ComfyUI/custom_nodes，然后重启 ComfyUI、刷新浏览器，在 Binyuan 分类搜索双语采样器。

必须一起保留 __init__.py、js、locales、LICENSE、pyproject.toml 及插件的其他运行文件。不能只发一个 Python 文件，否则可能缺少 LoRA 面板或双语标签。不要同时安装两个同 ID 的双语版副本。更新前备份原目录；原工作流默认不开启高级模式，噪声强度默认1，保持原设置。

旧节点没有显示新增选项时，先重启后端并刷新网页；仍没有则重新添加节点。工作流不附带模型，对方需重新选择自己安装的扩散模型、CLIP、VAE、LoRA。工作流若使用其他第三方节点，也要单独安装。

分发文件夹时可以排除 __pycache__ 和 .bak-* 备份文件；不要把真实模型、私人图片或工作流当作插件依赖一起发送。

二、兼容性与验证范围（发给使用者前请保留）

本说明核对时的本机 ComfyUI 内核为0.37.0。新增功能已做节点导入、输入接口、步数裁切、加噪开关及噪声幅度测试；不是对所有模型逐一进行完整出图验证，也没有验证所有旧版内核。

本节点不承诺“所有模型、所有整合包、所有ComfyUI版本通用”。模型能否加载，取决于内核是否支持该架构、相关依赖是否齐全、模型/CLIP/VAE是否配套。支持列表和模型下拉框不等于每个组合都经过测试。不能把0.37.0理解为已证明的最低版本，也不能保证更高版本永远兼容。

GGUF功能需要 ComfyUI-GGUF；Qwen-Image-2.1功能需要提供 TextEncodeQwenImage21 等对应接口的内核，以及配套模型、文本编码器和VAE。注意力后端依赖当前环境、硬件及相关库。节点目录可分发，但仅复制目录不会补齐这些依赖。

新增采样选项作用于本节点已有的采样流程；不同架构、蒸馏/加速模型、LoRA及采样器对参数的反应不同。跨模型传递LATENT或CONDITIONING前必须确认兼容，不能仅凭接口颜色相同判断。

三、新增采样选项

1. 总步数（steps）：原来的步数，不是新增一份重复计数。高级模式下决定完整采样日程；连接外部步数时，以连线输入为准，节点里保存的数值不再决定实际步数。
2. 高级分段采样（advanced_sampling）：默认关闭。开启后用起始/结束步数控制采样，忽略重绘强度；关闭后使用原有普通采样逻辑。
3. 起始步数（start_at_step）：从0计数。0从头开始；10跳过前10步。
4. 结束步数（end_at_step）：采样停止边界。总步数20、起始10、结束20，实际执行后10步。默认10000表示一直到日程末尾，不会实际运行一万步。
5. 添加噪声（add_noise）：仅高级模式下生效。开启时添加初始随机噪声，关闭时不添加。它不会消除输入LATENT里已有的噪声。
6. 保留剩余噪声（return_with_leftover_noise）：仅高级模式下生效。第一段提前停止、还要交给后续节点时打开；最终出图段关闭。关闭时若提前停止，会将日程终点设为零。
7. 初始噪声强度（noise_strength）：普通/高级模式都能使用，范围0～2，默认1。1保持标准幅度，0.5减半，0.25为四分之一，0不添加初始随机噪声。高级模式“添加噪声”关闭时，本项无效。

结束边界不大于起始边界，或起始已超过日程末尾时，不执行采样，返回输入潜空间。

四、重绘强度和初始噪声强度的区别

普通模式：重绘强度决定所使用的采样日程，初始噪声强度缩放新增随机噪声，两者可以一起用。普通模式不读取高级模式的“添加噪声”开关；想不新增初始噪声，可将初始噪声强度设为0。

高级模式：重绘强度不生效，由总步数、起始步数和结束步数决定日程；“添加噪声”开启后，再由初始噪声强度调节幅度。

初始噪声强度不控制某些随机采样算法在迭代中额外注入的噪声，也不改变步数或去除已有噪声。强度0不等于原图原样返回，去噪运算仍可能改变图像。强度0.5也不代表画面变化减少一半，更不保证画质提升。

连接外部SIGMAS时，以外部完整噪声日程为准。高级模式对它进行分段；普通模式直接使用它，内部重绘强度不再控制该日程。不要改动原SIGMAS，也不要给第二段再接已经裁切过的日程后重复填写起始步数。

五、示例A：一次20步拆成两段接力

第一段：高级分段开，总步数20，起始0，结束10，添加噪声开，保留剩余噪声开，初始噪声强度1。
第二段：高级分段开，总步数20，起始10，结束20，添加噪声关，保留剩余噪声关；此时初始噪声强度不参与计算。

连线：
- 第一段 MODEL → 第二段 external_model。
- 第一段 CLIP → 第二段 external_clip。
- 第一段 VAE → 第二段 external_vae。
- 第一段 LATENT → 第二段 external_latent。
- 如需完全继承提示条件，再连接 POSITIVE、NEGATIVE 到对应外部条件。

第二段选择“继承上游模型”和“外部Latent优先”。保持相同的模型、调度器、总步数；如接外部SIGMAS，两段接同一份完整日程。不得用IMAGE或DENOISED代替尚未完成采样的LATENT接力。

这仍是总共20步，不是20步以后再优化10步。同模型、同条件、同种子分段后与一次20步相近是正常现象。多步求解器的历史状态及随机采样器的随机序列会影响结果，不能承诺拆段后逐像素一致。

六、示例B：完成图片后，再做一次细化

第一段先正常完成采样：例如总步数20，保留剩余噪声关。
第二段接第一段完成后的LATENT，关闭高级分段采样，采样步数可先设10，重绘强度先试0.20，初始噪声强度先保持1。

这些数值只是起点，不是适用所有模型的最优设置。固定种子，先调重绘强度，再单独试初始噪声强度0.5，避免同时改变多个参数。第一段从空Latent生成通常保持初始噪声强度1。

第二段步数若连着同一个整数常量，改节点内部显示数值不会生效；要独立10步，就断开第二段步数线或使用单独的整数输入。

要在第二段使用新提示词，应断开对应外部正/负条件线，否则继承的条件优先。不要重复叠加已经包含在继承MODEL里的同一个LoRA，除非这是有意的叠加。

需要放大后细化，可在两段之间加入兼容的潜空间放大节点。跨模型架构应先通过图像及目标VAE转换，不直接传不兼容的LATENT。细化会改变细节，并不保证优于直出。

七、输出、预览及常见问题

- LATENT：本次实际采样结果，可能包含剩余噪声，供下一段接力。
- DENOISED：采样器提供的去噪预测；不是尚未完成采样时应传给下一段的LATENT。
- IMAGE：高级模式保留剩余噪声时，尽可能解码DENOISED预览；没有预测时可能仍带噪。预览看起来完整不代表LATENT已经完成去噪。
- 重绘强度改了没效果：先检查高级模式是否开启、是否连接了外部SIGMAS，以及是否从空LATENT生成。空LATENT普通生成会把低重绘强度保护到1。
- 噪声强度改了没效果：检查是否在高级模式关闭了添加噪声，或当前区间没有可执行步数。
- 总步数明明20却没有第二段效果：检查外部整数输入；例如实际总步数8、第二段起始10，就没有后续步数。
- 对比看不出区别：确认比较节点连接的是不同分支，标签符合实际LoRA开关，再区分“分段完成一次采样”和“成图后额外细化”。
- 更新后没有新控件：重启后端、刷新网页；必要时重新添加节点，并保留原工作流备份。

八、原有功能详细说明

以下为模型加载、Qwen编辑、LoRA和基础参数说明。其中关于“重绘强度”的普通使用建议，均以关闭高级分段且未用外部SIGMAS接管日程为前提。

Binyuan Sampler V2.2 EN（中英双语版）详细使用说明

一、节点简介

节点名称：Binyuan Sampler V2.2 EN｜中英双语版
节点分类：Binyuan
节点标识：BinyuanUltimateSamplerEN

该节点是一体化 ComfyUI 采样器，可以完成：

1. 加载整包 Checkpoint，或分别加载扩散模型、CLIP、VAE。
2. 编码正面与负面提示词。
3. 创建空 Latent，或接收外部 Latent、上游图像。
4. 接收外部 Sigmas，自定义采样噪声曲线。
5. 支持 Qwen-Image-2.1 文生图、原生参考编辑和 VAE 传统重绘。
6. 加载一个或多个 LoRA。
7. 输出图像、模型、CLIP、VAE、条件和 Latent，方便多阶段串联。
8. 生成完成后按需清理显存。

插件没有绑定特定整合包路径，复制到其他标准 ComfyUI 环境也可以使用。对方仍需自行准备对应模型、CLIP、VAE、LoRA，以及所用模型需要的 ComfyUI 内核节点。


二、安装方法

1. 将整个插件文件夹复制到：

   ComfyUI/custom_nodes/

2. 文件夹名称可以更改，但不要删除其中的 __init__.py、js、locales 等文件。
3. 完全关闭并重新启动 ComfyUI。
4. 在节点菜单的 Binyuan 分类中添加：

   Binyuan Sampler V2.2 EN｜中英双语版

如果更新插件后界面没有变化，请执行浏览器强制刷新（Ctrl+F5），必要时清理前端缓存后重新打开 ComfyUI。


三、加载模型

【加载模式】

1. Checkpoint（整包 Checkpoint）

   适用于模型、CLIP、VAE 已打包在同一 Checkpoint 中的模型。
   在 Checkpoint 选项中选择模型即可。

2. Separate（分离式）

   适用于 Flux、Qwen、SD3 等分离模型，需要分别选择：

   - 扩散模型
   - CLIP_1
   - CLIP_2（模型需要时才选）
   - CLIP 类型
   - VAE

【CLIP 类型】

必须与模型架构匹配。Qwen-Image-2.1 应选择 qwen_image_2.1，并搭配对应的 Qwen 图像文本编码器。

【VAE】

VAE 必须与模型 Latent 格式匹配。Qwen-Image-2.1 应使用对应的64通道 Qwen VAE，不能随意使用 SDXL、Flux 或旧 Wan VAE。

VAE 的主要作用：

- 将图像编码成 Latent。
- 将采样结果解码成图像。
- VAE 本身通常不决定生成画布尺寸，画布由空 Latent、外部 Latent或参考图分支决定。


四、串联模式与外部输入

【串联模式】

1. 使用自身模型

   使用当前节点内部选择的模型、CLIP和VAE。

2. 继承上游模型

   优先使用连接到“外部模型、外部CLIP、外部VAE”的对象，适合两个采样器串联。

3. 自动检测

   根据当前连接情况选择可用对象。复杂工作流建议明确选择“使用自身模型”或“继承上游模型”，避免误判。

【外部模型】

接收上游 MODEL。模型类型必须与当前使用的 CLIP、VAE、Conditioning 和 Latent 相匹配。

【外部CLIP】

接收上游 CLIP。用于当前节点重新编码提示词。

【外部VAE】

接收上游 VAE。用于上游图像编码及最终图像解码。

【外部Latent】

接收上游 LATENT，适合相同模型家族的二次采样。

重要：不同模型家族的 Latent 通道数、缩放倍率和含义可能不同。例如 Krea/Flux 与 Qwen-Image-2.1 之间不要直接传 Latent。跨模型串联时，应传递 IMAGE，由第二个模型使用自己的 VAE重新编码。

【外部正面条件、外部负面条件】

接收上游 CONDITIONING。在继承条件时，要确保条件来自兼容的 CLIP和模型架构。

【外部Sigmas】

连接后，外部 Sigmas 会接管采样噪声序列。此时节点内部的步数、调度器和重绘强度不再完整决定采样过程。


五、Latent输入源与尺寸优先级

【Latent输入源】常用选项：

1. 空Latent

   用于普通文生图。画布由节点中的宽度、高度决定。

2. 外部Latent优先

   连接外部 Latent 时优先使用它。最终尺寸由外部 Latent 决定。

3. 上游图像优先

   有上游图像时，按当前模型和编辑模式处理图像。

4. 上游图像拼接

   将多张上游图像横向拼接，再作为输入或参考。多图尺寸差异较大时，可能发生缩放。

【尺寸优先级】

当多个尺寸来源同时存在时，按以下原则判断：

1. 已启用的外部 Latent：最终画布由外部 Latent 决定。
2. Qwen原生参考编辑：由处理后的第一张参考图决定。
3. Qwen VAE传统重绘：由第一张上游图像决定。
4. 普通文生图：由节点的自定义宽度和高度决定。

外部 VAE 不直接决定尺寸；“Qwen参考分辨率”也不会覆盖普通文生图的自定义宽高。


六、尺寸助手、宽度和高度

【尺寸助手】

选择预设尺寸，或者选择“自定义”后手动输入宽度和高度。

【宽度、高度】

普通文生图时，这两个参数决定空 Latent 的画布。

建议：

- Qwen-Image-2.1 尽量使用16或32的倍数。
- 无法整除模型下采样倍率的尺寸会被对齐，最终可能相差几像素。
- 例如1140不能被16整除，可能输出1136；建议改为1136或1152。
- 1440×2160可以被16整除，可以准确建立对应画布。

注意：连接外部 Latent，或进入参考图编辑/重绘模式后，自定义宽高可能不再是最高优先级。


七、Qwen参考分辨率

该参数只用于 Qwen-Image-2.1 参考图处理，不应控制普通文生图尺寸。

作用：将参考图按原宽高比缩放到大约“参考分辨率×参考分辨率”的总像素预算，再送入视觉编码器与VAE。

常用值：

- 0：尽量保持参考图原尺寸，只进行32像素对齐。
- 768：显存占用较低，参考细节较少。
- 1024：默认平衡值。
- 1536：保留更多参考细节，但速度更慢、显存占用更高。
- 2048及以上：需要较大显存，不代表一定能提高最终画质。

在“原生参考编辑”中，它还会影响最终画布，因为官方编辑流程要求空 Latent 与第一张参考图尺寸匹配。

在“VAE传统重绘”中，插件会按原图尺寸处理，相当于内部使用参考分辨率0，因此界面上的参考分辨率不会改变重绘画布。

在没有参考图的普通文生图中，该参数不影响最终宽高。


八、Qwen编辑模式

【Auto｜自动】

- 没有上游参考图：普通文生图，使用自定义宽高。
- 连接上游参考图：自动进入原生参考编辑。
- 用于兼容旧工作流和快速使用。

【Native reference edit｜原生参考编辑】

运行逻辑：

   参考图 → 视觉/参考条件
   空Latent → 开始采样

特点：

- 属于 Qwen-Image-2.1 官方参考编辑方式。
- 更适合换背景、换服装、改变姿势、重构场景、多图融合。
- 参考图不是传统图生图的初始画布，构图可能明显改变。
- 初始 Latent 为空，因此重绘强度低于1容易产生异常；插件会自动按1.0保护。
- 最终画布跟随第一张经过“Qwen参考分辨率”处理后的参考图。

保持参考图原尺寸的方法：

   Qwen参考分辨率 = 0

【VAE redraw｜VAE传统重绘】

运行逻辑：

   上游图像 → 当前Qwen VAE编码 → 初始Latent → 加噪重绘

特点：

- 更接近传统图生图。
- 保留原画布、主体位置和基本构图。
- 重绘强度真正生效。
- 适合二阶段细化、修复、增强材质和有限幅度编辑。
- 上游图像会按原尺寸进行必要的32像素对齐。

推荐重绘强度：

- 0.10～0.20：非常轻微的细节修复。
- 0.20～0.35：轻度优化，构图稳定。
- 0.35～0.50：常规二次采样，推荐范围。
- 0.50～0.65：明显改变细节、服饰或背景。
- 0.65以上：变化较大，人物和构图可能偏离。


九、同时连接参考图、VAE和外部Latent时

如果外部 Latent 被启用（例如串联模式为“继承上游模型”，或Latent输入源为“外部Latent优先”）：

- 外部 Latent决定最终画布和采样起点。
- 参考图仍然作为Qwen视觉条件参与生成。
- Qwen参考分辨率只控制参考图的编码尺寸。
- VAE负责编码参考图和解码最终结果。
- 重绘强度可以作用于外部 Latent。

推荐让外部 Latent 与参考图来自同一张、同一比例的图像，并将Qwen参考分辨率设为0。否则可能出现构图偏移、裁切感或参考条件与画布不一致。

如果外部 Latent来自不同模型家族，请断开它，只连接IMAGE，然后使用VAE传统重绘。


十、采样参数

【seed】

随机种子。相同模型、条件、尺寸、采样器和参数下，固定种子可帮助复现结果。

【生成后控制】

- fixed：生成后保持种子。
- randomize：每次生成后随机改变种子。
- increment/decrement（如果界面提供）：每次加一或减一。

【步数】

采样迭代次数。不同模型推荐值不同。步数过高不一定提高画质，反而会增加时间。

【CFG】

提示词引导强度。部分新模型适合较低CFG。Qwen或蒸馏模型应优先参考模型作者推荐值。

【Flux引导】

用于需要内嵌 guidance 的Flux类架构。非Flux模型可能不使用该参数。

【采样算法】

例如 euler、er_sde 等。更换算法会改变细节、锐度和随机性。

【调度器】

决定噪声随采样步骤的分布，例如 simple、beta等。若连接外部 Sigmas，则以外部Sigmas为准。

【重绘强度】

- 1.0：完整噪声过程，适合空Latent文生图或Qwen原生参考编辑。
- 小于1.0：保留初始Latent的部分结构，适合外部Latent或VAE传统重绘。
- 空Latent文生图设置低于1.0会缺少完整初始噪声，容易产生花图；插件会自动保护为1.0。


十一、LoRA使用

节点支持两种LoRA输入方式：

1. 节点内部LoRA列表/添加LoRA界面。
2. 连接“Binyuan LoRA设置”节点到“LoRA设置”输入。

可以叠加多个LoRA。每个LoRA通常包含：

- 是否启用
- LoRA文件名
- 模型强度
- CLIP强度

建议：

- 第一次测试使用0.6～1.0。
- 多个LoRA叠加时适当降低每个LoRA强度。
- LoRA必须与当前模型架构兼容。
- Qwen LoRA不能保证能用于Flux/SDXL，反之亦然。
- LoRA文件不存在时，插件会在控制台给出警告并跳过。


十二、上游图像接口

上游图像1、2、3可用于参考编辑、多图参考或图像拼接。实际显示的接口数量可能由前端动态添加功能决定。

一般建议：

- 单图重绘：只连接上游图像1。
- 多图参考：分别连接多个上游图像端口。
- 第一张参考图通常决定编辑画布。
- 多图尺寸与比例差异过大时，参考关系可能不稳定。


十三、输出接口

【IMAGE／图像】

最终VAE解码后的图像，可连接预览图像、保存图像或下一个采样器的上游图像。

【MODEL／模型】

当前实际使用并已应用LoRA等修改的模型，可传给下游节点。

【CLIP】

当前实际使用的CLIP，可供下游重新编码提示词。

【VAE】

当前实际使用的VAE。

【LATENT】

本次采样后的Latent结果。只应传给Latent格式兼容的模型。

【POSITIVE／正面条件】

当前正面Conditioning。

【NEGATIVE／负面条件】

当前负面Conditioning。

【DENOISED／降噪Latent】

采样器返回的降噪预测Latent，可用于某些高级二阶段流程。它与普通采样结果Latent含义不同，不要在不清楚下游要求时随意替换。


十四、典型工作流

方案A：普通Qwen文生图

1. 选择Qwen扩散模型、CLIP和VAE。
2. CLIP类型选择qwen_image_2.1。
3. 不连接外部Latent和上游图像。
4. 尺寸助手选择自定义。
5. 设置宽度、高度。
6. Qwen编辑模式选择自动。
7. 重绘强度设为1.0。

最终尺寸由自定义宽高决定，Qwen参考分辨率不参与。

方案B：Qwen原生参考编辑

1. 将参考图连接到上游图像1。
2. Qwen编辑模式选择原生参考编辑。
3. 保持原图尺寸时，将Qwen参考分辨率设为0。
4. 需要统一参考像素预算时，可设为1024或1536。
5. 重绘强度保持1.0。

方案C：Qwen传统二次重绘

1. 将第一阶段IMAGE连接到第二阶段的上游图像1。
2. 第二阶段选择正确的Qwen模型、CLIP和VAE。
3. Qwen编辑模式选择VAE传统重绘。
4. 重绘强度先从0.35开始测试。
5. 不要同时连接来自其他模型家族的外部Latent。

方案D：相同模型的Latent二次采样

1. 第一阶段LATENT连接第二阶段外部Latent。
2. 模型、VAE和Latent格式必须兼容。
3. 串联模式选择继承上游模型，或Latent输入源选择外部Latent优先。
4. 第二阶段重绘强度设置为0.20～0.60。
5. 需要完全控制噪声曲线时可连接外部Sigmas。

方案E：不同模型之间串联

正确方式：

   第一模型IMAGE → 第二模型上游图像 → 第二模型自己的VAE编码

错误方式：

   第一模型LATENT → 不同架构的第二模型外部Latent


十五、自动清理显存

开启“生成后清理显存”后，节点会在生成结束后尝试释放不用的模型缓存并执行内存回收。

适合：

- 显存较小。
- 经常切换大模型。
- 多阶段工作流容易爆显存。

可能的影响：

- 下一次生成需要重新加载部分模型，速度会变慢。
- 连续批量生成时不一定适合开启。


十六、常见问题排查

问题1：自定义为竖图，结果还是1024×1024

检查：

- 是否连接了外部Latent。
- 是否接入了参考图并使用原生参考编辑。
- 工作流中实际保存的宽高是否正确。
- 插件是否已经更新并重新启动ComfyUI。

新版逻辑中，没有参考图的Qwen普通文生图应使用自定义宽高，不再被Qwen参考分辨率覆盖。

问题2：降低重绘强度后出现花图

常见原因是对空Latent文生图使用了小于1.0的重绘强度。普通文生图和原生参考编辑使用1.0；需要低重绘强度时，请使用外部Latent或VAE传统重绘。

问题3：二阶段画面与第一阶段相差太远

- 使用VAE传统重绘而不是原生参考编辑。
- 降低重绘强度，例如从0.45降到0.30。
- 保持相同宽高比。
- 检查提示词是否要求大幅改变场景。
- 检查第二阶段是否换了模型或叠加了高强度LoRA。

问题4：连接外部Latent后尺寸不听自定义宽高

这是正常行为。外部Latent已经包含画布尺寸，所以它优先于节点宽高。

问题5：参考图与输出构图对不上

- 原生参考编辑本来就允许重构画面。
- 想保留构图请选择VAE传统重绘。
- 外部Latent与参考图同时使用时，两者最好尺寸、比例和内容一致。
- 参考分辨率设为0可减少参考图缩放。

问题6：提示VAE通道不匹配

当前VAE与模型架构不兼容。请更换为模型对应的VAE，不要强行继续采样。

问题7：插件复制给别人后模型下拉框不同

插件不会附带模型文件。下拉列表来自对方ComfyUI的models目录。对方必须自行安装相应模型、CLIP、VAE和LoRA。


十七、推荐原则总结

注意力后端（新增设置）：

- 自动稳定：节点自己加载 Krea2 或 Qwen-Image-2.1 模型时，优先使用环境中可用的 Comfy Kitchen；如果不可用，使用 ComfyUI 分块注意力。外接模型与其他架构保持原设置。
- 内核默认：完全遵循 ComfyUI 的启动参数。若 PyTorch/cuDNN 注意力报 mha_graph 错误，可改选自动稳定。
- Comfy Kitchen：明确指定该后端；当前环境未提供时会提示错误。
- 分块省显存：明确指定 ComfyUI 的分块注意力，通常更慢。

该设置只作用于此采样器使用的模型，不修改 ComfyUI 的全局注意力配置。独立采样器无需额外连接“模型注意力后端”节点。使用外接模型时，“自动稳定”保留上游已经设置的后端。


1. 普通文生图：空Latent、自定义宽高、重绘强度1.0。
2. 大幅参考编辑：原生参考编辑、重绘强度1.0。
3. 保持构图二次优化：VAE传统重绘、重绘强度0.20～0.50。
4. 同模型二次采样：可以传外部Latent。
5. 不同模型串联：传IMAGE，不要直接传Latent。
6. 同时连接外部Latent和参考图：Latent决定画布，参考图决定视觉条件。
7. Qwen参考分辨率只处理参考图，不控制普通文生图尺寸。
8. 模型、CLIP、VAE、LoRA和Conditioning必须与架构匹配。
